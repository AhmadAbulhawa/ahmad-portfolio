# V11: genuine bidirectional helical staircase
The previous layout re-created each gallery pose with modulo arithmetic, teleporting an old card from top to bottom as the selected index changed. It also relied on CSS transitions between unrelated end positions. This revision renders a continuous signed spiral path based on floating internal camera progress (0..3), advances one whole card per wheel gesture, and uses requestAnimationFrame for a symmetrical 1200ms ease-in-out animation completely independent of scroll distance. The selected panel always faces front (x=0,y=0,z=0,rotY=0,scale=1). The upcoming panels form a descending circular staircase under it, and the previous panels rise behind it without jumping. Wheel gestures during animation are ignored; reverse scroll traverses the exact same Cartesian path backward. All original video files and story-gating behavior are unchanged.
