# Three cinematic films + helical gallery (draft)
Sequence: 01 Man putting goggles on, 02 full dissolve, 03 goggle shattering, 04 orbiting glass project gallery. Each video has its own progress interval; CSS animated quote overlays the second chapter. Video timeline advances in response to scroll and reverses on upward scroll. A video's 1.5x equivalent is achieved by allocating less scroll travel to it, not by forcing autoplay. The fourth chapter uses a real cylindrical 3D helix positioning formula for four clickable portfolio projects. Native scrolling and keyboard navigation remain enabled.
